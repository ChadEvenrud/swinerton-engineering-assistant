The product

Engineering Assistant

An engineer submits a question. The backend publishes an event. Kafka or RabbitMQ holds it. An AI worker consumes it and the answer comes back to the UI. The request is asynchronous. The agent stays simple.

Target flow

User → Frontend → Backend API → Kafka / RabbitMQ → Agent worker → Backend → Frontend

Where the code lives

frontend/     Question form + result view
backend/      REST API, event producer, result endpoint
agent/        Consumer + AI worker
messaging/    Event schema and broker helpers
tests/        Automated tests
docs/         This site + architecture notes
challenges/   Weekly assignment briefs
submissions/  Individual weekly hand-ins

Local brokers

docker compose --profile kafka up
docker compose --profile rabbitmq up

Pick one broker for the final build in Week 4. Copy .env.example to .env. Never commit API keys.
