Six weeks

Weekly challenges

Everyone completes the lab, then opens a pull request that adds their work under submissions/week-NN/your-github-username/. Copy the template in that week’s folder. Full briefs live in challenges/ in the repo.

How to submit View submissions
Week 1

Messaging Fundamentals

Draw the producer → broker → two consumers picture. Answer: what happens if Consumer B is unavailable when the producer sends the message?

Week 2

Apache Kafka

Run Kafka locally. Produce and consume an EngineeringQuestionSubmitted event. Stop the consumer, produce more messages, restart, and write what you observed.

Week 3

RabbitMQ

Repeat the Week 2 exercise on RabbitMQ. Same event. The point is the comparison, not a second API to memorize.

Week 4

Kafka vs RabbitMQ

Choose a broker for (1) an ERP employee-update event with five consumers, and (2) a document handed to one available AI worker. Explain why.

Week 5

GitHub Actions fundamentals

Describe a first PR pipeline: checkout, install, test, build. Include the YAML you tried, or a screenshot of a green workflow run.

Week 6

CI/CD and secrets

Show a fuller pipeline (lint, tests, builds). Confirm no API keys live in source. Secrets belong in GitHub Actions secrets.
