How to contribute

Never push to main. Branch, add your files, open a PR, and get a teammate to review it.

Submission steps →

Get onto the repo

  1. Create a GitHub account if you do not have one.
  2. Send your GitHub username to a repo admin so you can be added as a collaborator.
  3. Clone the repo and work on a branch named after you and the work, for example challenge/week-01-yourname or feature/question-form.
  4. Open a pull request. That is the hand-in.
