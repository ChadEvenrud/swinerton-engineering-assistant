Pull requests are the hand-in

Submit your week

Do not push to main. Your weekly challenge is a branch plus a pull request that adds one folder with your GitHub username.

Folder to add

submissions/week-01/your-github-username/
  README.md          ← required, start from TEMPLATE.md
  notes.png          ← optional diagram or screenshot
  producer.py       ← optional code from the lab

Commands

git clone https://github.com/ChadEvenrud/swinerton-engineering-assistant.git
cd swinerton-engineering-assistant
git checkout -b challenge/week-01-yourname

# copy the template, then write your answers
# submissions/week-01/TEMPLATE.md
# → submissions/week-01/your-github-username/README.md

git add submissions/week-01/your-github-username
git commit -m "Submit week 1 challenge"
git push -u origin challenge/week-01-yourname

Then open a pull request on GitHub. Title it Week 1: yourname. Ask a teammate to review. After it is merged, your work is in the shared repo.

Product work uses the same rule

App changes go on feature/... branches against frontend/, backend/, agent/, messaging/, or tests/. Same review path. Secrets never go in the commit.
