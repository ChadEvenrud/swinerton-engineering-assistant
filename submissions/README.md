# Weekly submissions

Each person adds **their own folder**. Do not edit another teammate's files.

```
submissions/week-01/<your-github-username>/README.md
```

1. Copy that week's `TEMPLATE.md` into your folder as `README.md`.
2. Add diagrams, screenshots, or lab code next to it.
3. Open a pull request. See [CONTRIBUTING.md](../CONTRIBUTING.md).
